**中心の問い**: Phase 2 の後付けモデル（GA＋GatedNorm、massive activation を除去済み）は、元のモデルより**三値化しやすい**か。

根拠は 2 つある。
- **CAT-Q 再現で見つけた障害**: CAT-Q-Private の再現で、「窓出力の MSE 最小化が massive activation（MA）チャネルの振幅を系統的に縮め（回帰希釈）、直後の RMSNorm がそれを方向誤差に変えて増幅する」ことを見つけている（Norm 前の相対誤差 0.75 → Norm 後 1.52、top-1 一致 3%）。つまり MA は三値 PTQ の障害そのもの。後付けモデルでは、この MA が 7200 → 248 に消えている。
- **Phase 2 の感度分析**: 後付けモデルは Attention の重みの 4bit 量子化にむしろ強くなっていた。逆に、元の構造のまま MA を消したモデル（B1）は、Attention の重みが 2〜5 倍敏感になっていた。三値化は、この差が最も拡大して現れるはずの設定。

## 1. 問いと仮説

**RQ5（主）**: 同じ三値化器（CAT-Q、W1.58A16）で、後付けモデル（M3）は元モデル（M0）より量子化後の劣化が小さいか。

- H5a: M3 の三値化後の C4 PPL は、M0 の三値化後より低い。自分の FP からの劣化率（PPL 比）で見ても、元モデルに対する絶対値で見ても低い。
- H5b: 元の構造で外れ値を抑えたモデル（M1）は、三値化で M0 より**悪化**する（Phase 2 の W4A16 感度の外挿）。つまり「外れ値を減らせば量子化しやすくなる」のではなく、「外れ値の機能をゲートに移すこと」が効く。
- H5c: M0 の三値化では、MA のある層（L2〜L27 の dim 35、step-up の L2 MLP）で再構成誤差が集中する。M3 ではそれが消える（層ごとの CAT-Q 損失と Norm 前後の誤差で確認）。

**RQ6**: 三値の重みに低ビットの活性（A8 / A4）を組み合わせたとき、後付けの効果はさらに大きいか。

- H6: W1.58A8 では 3 モデルの差は小さい（CAT-Q 論文でも A8 と A16 はほぼ同等）。W1.58A4 では M3 が M0 を大きく上回る。Phase 2 で、per-token INT4 の崩壊が 1/24 に減っているため。
- 一方、M3 は外れ値が down_proj の入力に移っているので、A4 では down_proj がボトルネックになる見込み。down_proj の入力だけを 8bit に残す構成、または online Hadamard を当てる構成（BitNet v2 型）を副条件にする。

**RQ7**: 後付けのゲート（GatedNorm / GA、bf16 のまま 2.3M パラメータ）は、三値化の誤差を補償する「安価な回復用パラメータ」として使えるか。

- H7: 三値化後に、ゲートと Norm の重みだけを元の FP モデルへの KL 蒸留で再学習すると、PPL の劣化の大部分を回復できる。同じパラメータ数の LoRA や Norm のみの再学習より効率が良い。

## 2. 対象モデル（重みを量子化する元）

| ID | モデル | 備考 |
|---|---|---|
| M0 | Qwen3-0.6B-Base（元モデル） | ベースライン |
| M1 | Phase 2 の B1（元の構造、λ = 3e-3） | 外れ値を抑えたがゲートなし。W4A16 に弱い |
| M3 | Phase 2 の B3h（GA＋GatedNorm、λ = 3e-3） | 主対象。MA 7200 → 248、KL 0.029 |
| （M3'） | B3h（λ = 1e-2） | 余力があれば。より強く外れ値を抑えたもの |

- M1 / M3 は FP の時点で M0 より少し劣化している（WikiText-2 PPL +7.6% / +4.4%）。比較は次の 2 通りで行う。
  1. **元モデル M0（FP）に対する絶対値**（実用上の意味）
  2. **それぞれの FP からの劣化**（量子化のしやすさ）
- 後付けの追加パラメータ（ゲート 2.3M、Norm、埋め込み / lm_head）は bf16 のまま残し、実効ビット数に含めて報告する（0.6B では約 +0.08 bit/重み）。
- 参考: CAT-Q-Private の Qwen3-0.6B（post-trained 版）の結果（C4 PPL 21.97 → 87.6）で、統合した実装が同じ結果を出すかを確かめる。

## 3. 量子化器と条件

**重み**（量子化するのは q/k/v/o/gate/up/down。グループサイズ 128）

| ID | 方式 | 役割 |
|---|---|---|
| Q1 | RTN 三値（TWN 型: 閾値 0.7·mean\|w\|、スケールは閾値超えの平均） | 下限の参照。数分 |
| Q2 | GPTQ 三値（ヘシアン誤差補正付き。三値グリッドは Q1 の α で固定） | 標準的な PTQ。数十分。自前実装 |
| Q3 | **CAT-Q 三値**（CAT-Q-Private の v3 設定: 512×2048 の C4、60 エポック、LoRA r=4、CS なし） | 主。0.6B で約 1.7 時間/本 |
| Q4 | W4 の参照（GPTQ INT4 g128、NVFP4） | 三値との位置関係を示す |

**活性**: A16 / A8（per-token INT8、BitNet と同じ）/ A4（NVFP4 と per-token INT4）。まず三値化後に事後的に掛ける（安価）。P2 の余力で、CAT-Q の再構成中にも A8 を掛ける「活性を考慮した三値化」を試す（論文の W1.58A8 設定）。

**A4 の副条件**:
- down_proj の入力だけ 8bit に残す（M3 の外れ値の移動先）
- down_proj の入力に online Hadamard を当てる（重み側は H を畳み込んでから量子化する）

## 4. 実験段階

### P0: 統合（1 日）

- CAT-Q 再現実装（`catq`）を git submodule `third_party/CAT-Q-Reproduction` としてマウントし、uv の editable な path 依存として使う。`catq` 側の変更は同リポジトリにコミット・push し、本リポジトリの submodule の参照を更新する。
- **後付けモジュールとの両立**: CAT-Q は o_proj などを `setattr` で CATQLinear に置き換える。GA のゲートは元の o_proj に付けたフックで掛けているため、置き換えるとゲートが黙って外れる。置き換えの後に GA のフックを付け直す関数を `retrofit.py` に追加する。「CAT-Q の fp モードでの出力が、置き換え前とビット一致する」テストで確かめる。GatedNorm はモジュールとして層に入っているので影響しない。
- **保存と復元**: CAT-Q は HF の `save_pretrained` で保存するが、後付けモデルは `save_retrofit` 形式（三値を焼き込んだ state_dict＋後付けの設定）で保存する。
- **三値化のテスト**: Q1 / Q2 の既知値テスト。GPTQ の誤差補正が RTN 以下の再構成誤差になること。
- **再現確認**: CAT-Q-Private の Qwen3-0.6B（post-trained）の v3 設定を、本リポジトリの呼び出し経路で回し、C4 PPL が 87.6 前後になることを確かめる（約 2 時間）。

### P1: 安価な量子化器のスイープ（0.5 日）

- Q1、Q2、Q4 × M0 / M1 / M3 × A16 / A8 / A4 を回す。
- 評価は、C4-val PPL（CAT-Q-Private と同じ条件）、WikiText-2 PPL、held-out KL（M0 の FP が基準）。
- 目的:
  - 三値化で M0 / M1 / M3 に差が出るかを安く確かめる。
  - Q2 の GPTQ 三値が、CAT-Q の比較相手として十分かを見る（CAT-Q 論文で GPTQ の W2 が崩壊しているのと同様の崩壊が出るか）。

### P2: CAT-Q 三値（主実験、1.5 日）

- Q3 × M0 / M1 / M3（W1.58A16）。1 本約 1.7 時間＋評価。
- 評価:
  - C4 / WikiText-2 の PPL、held-out KL、lm-eval（論文の 5 タスクのプロトコル: PIQA / ARC / HS は acc_norm、WG は acc。＋LAMBADA）
  - 事後的な A8 / A4
- **機構の確認（H5c）**:
  - CAT-Q の窓ごとの損失ログを層ごとに比べる。
  - 三値化後の残差ストリームで、MA と残差シンクが再び現れるか（Phase 1 の計測一式）。
  - 最終層の Norm 前後の相対誤差と top-1 一致率（CAT-Q-Private の「回帰希釈」の診断）。
- 余力があれば: 活性を考慮した CAT-Q（再構成中に A8）× M0 / M3。

### P3: ゲートによる補償（1 日）

- P2 の三値化モデルで、三値化した重みは固定し、次のパラメータだけを M0 の FP への KL 蒸留で再学習する。
  - M3: ゲート（GatedNorm / GA）＋Norm の重み
  - M0: Norm の重みのみ
  - M0: 同じパラメータ数の LoRA（公平な対照）
- データは FineWeb-Edu 50M token。Phase 2 の学習スクリプトを流用し、`--new-only` 相当で「ゲートのみ学習」のモードを使う。
- 見るのは「PPL をどれだけ回復できるか（学習パラメータあたり）」。元計画の RQ4（ゲートのみの学習）にも答える。

### P4（任意）: Qwen3-1.7B-Base（3〜4 日）

- 0.6B の三値モデルは、zero-shot が偶然水準（約 35）に近く、MC 精度では差が見えにくい（CAT-Q-Private の所見）。1.7B なら CAT-Q の三値でも平均 43（偶然水準を十分上回る）。
- Qwen3-1.7B-Base に、B1 / B3h の後付け（λ = 3e-3、200M token）を行う。学習時間は 0.6B の約 3 倍（1 本約 16 時間）。
- そのうえで、CAT-Q × 3 モデル（1 本約 4 時間）と評価を行う。
- P2 で M3 の優位が見えた場合に実施する。

## 5. 評価の方針

- **主指標は PPL と KL**（0.6B では MC 精度が偶然水準近くで頭打ちになるため）。C4-val PPL は CAT-Q-Private の `run_ppl.py` と同じ条件（C4 validation、1024 token 以上の文書の先頭 1024 token）で測り、あちらの既存結果と直接比べられるようにする。
- 副指標は lm-eval（論文プロトコル）、RTN の活性量子化 ΔPPL、Phase 1 の外れ値指標。
- 実効ビット数（量子化しないパラメータを含む）とモデルサイズを併記する。
- すべて、Phase 2 と同じく JSONL / parquet と wandb（group `phase3-*`）に記録する。

## 6. 成功基準（暫定）

- **主（H5a）**: CAT-Q W1.58A16 で、M3 の C4 PPL が M0 より明確に低い。目安は「自分の FP からの PPL 比」で 2 割以上の改善。M0 の FP に対する絶対値でも下回る。
- **H5b**: M1 の三値化後が M0 以下。これで「ゲートに機能を移すことが効く」ことを、量子化の側からも示す。
- **H6**: W1.58A4 で M3 と M0 の差が A16 より大きい。
- **H7**: ゲートだけの再学習で、三値化による PPL の劣化（自分の FP からの増分）の半分以上を回復できる。
- **否定的な結果の扱い**: 三値化の難しさが MA 以外（重みの分布そのもの）で決まっている場合、M0 と M3 の差は出ない。それ自体も「活性の外れ値と重みの三値化の難しさは独立」という結果として報告する。

## 8. リスクと対策

| リスク | 対策 |
|---|---|
| CAT-Q の Linear 置き換えで GA のゲートが外れる（確認済み） | P0 でフックの付け直しと、fp モードでのビット一致テストを入れる |
| M1 / M3 は FP の時点で少し劣化している | 自分の FP からの劣化と、M0 に対する絶対値の両方で比べる |
| 0.6B の MC 精度が偶然水準で比べられない | 主指標を PPL / KL にする。必要なら P4（1.7B） |
| CAT-Q 実装が論文より弱い（1.7B で −7.6pt） | 3 モデルを同じ実装・同じ設定で比べるので、相対比較は有効。論文値との比較は主張しない |
| 外れ値の down_proj への移動が A4 で効く | down_proj の入力だけ 8bit に残す、または Hadamard を当てる副条件を置く |
| GatedNorm / GA が bf16 のまま残り、「純粋な 1.58bit」ではない | 実効ビット数を明記する。ゲートも 8bit にした条件を 1 本足す |
| 回転系 PTQ（QuaRot / SpinQuant）は、要素ごとのゲートと可換でなく相性が悪い | 今回は三値化と per-token 活性量子化に絞る。回転は down_proj 入力の online Hadamard だけに限定する |

## 9. 決定事項（2026-09-27）

1. **P4（1.7B）は、P2 の結果を見てから決める。**
2. **対象は Base 版のまま**（Phase 2 のモデルをそのまま使う）。論文値との直接比較は主張しない。
3. **CAT-Q 再現実装は、公開リポジトリ [CAT-Q-Reproduction](https://github.com/takuma104/CAT-Q-Reproduction)（旧 CAT-Q-Private）を git submodule としてマウントして使う。** 同リポジトリへのコミット・push は可。
4. **W4A4（SmoothQuant＋GPTQ＋NVFP4 など）の本格的な比較は後回し。** 本計画では W4 を参照程度（Q4）にとどめる。
